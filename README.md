# pi-plugins

Personal collection of custom plugins and extensions created by [@1bharath-yadav](https://github.com/1bharath-yadav) for [PI-Desktop](https://github.com/vastsa/PI-Desktop).

## Plugins

- [**openui-render**](./openui-render): Interactive OpenUI Lang renderer, Three.js 3D graphics, and Draw.io architecture diagramming extension for PI-Desktop conversations.
